<h1>PixelQuest
est une application web interactive qui permet aux utilisateurs d’explorer une large collection de jeux vidéo en s’appuyant sur une API externe.
Elle offre une interface moderne et responsive pour rechercher, filtrer, trier et consulter les jeux, tout en affichant des informations essentielles comme la jaquette,
la note, la date de sortie et les genres. L’utilisateur peut également ajouter des jeux à une liste de favoris grâce à un système de stockage local, 
et consulter une fiche détaillée pour chaque jeu. Le projet combine JavaScript, fetch API, gestion asynchrone et une organisation propre du code pour offrir une expérience fluide et intuitive.
